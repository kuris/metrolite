# ⚡ 서율 메트로 라이트 (Seoyul Metro Light)

정전된 가상 도시 **"서율"**의 지하철 노선을 복구하는 전기 연결 퍼즐 게임입니다.
타일을 터치해 45도씩(8방향) 회전시켜 전원역에서 모든 일반역까지 전기가 흐르게 만들면 클리어됩니다.

거의 암흑에 가까운 네이비 터널 속에서 전기 시안빛 파이프가 확 밝아지는 타격감과,
"신비한 터널을 질주하는 하이퍼 기차" 느낌의 사운드로, 1판당 10~30초 정도 가볍게 즐길 수 있는
"잠깐 하는 지하철 전기 복구 퍼즐"을 목표로 제작했습니다.

---

## ✅ 현재 완성된 기능

- **난이도(회전 방향) 선택 (신규)**: 게임 시작 전 "4방향 모드(쉬움)" / "8방향 모드(도전)" 중 하나를 고르는 선택 화면이 먼저 나타남
  - 4방향 모드: 상/하/좌/우로만 꺾이는 선로를 90도씩 회전 — 대각선을 쓰지 않는 기존 1~5번 노선만 플레이
  - 8방향 모드: 대각선까지 꺾이는 선로를 45도씩 회전 — 대각선/혼합 꺾임 노선(6~7번)을 포함한 전체 7개 노선 플레이
  - 선택에 따라 `rotationStep`(클릭 한 번의 45도 칸 수)과 플레이할 노선 목록이 자동으로 갈립니다
- **`index.html` + `assets/` 사운드 파일**로 동작 (외부 라이브러리 없음; 사운드만 CC0 음원 파일을 함께 배포)
- 모바일 세로 화면 기준 UI이며, PC에서도 **중앙 정렬된 모바일 폰 프레임** 형태로 표시
- 4×4 / 5×5 격자 퍼즐판, 타일 터치 시 **45도씩(8단계) 회전** — 8방향 원형을 전부 활용해 한 번 클릭할 때마다 45도씩 돌아가며, 8번 누르면 원래 모양으로 돌아옴
- 타일 종류 구현: 직선, ㄱ자 커브, T자 분기, 십자 교차, 전원역(⚡), 일반역(●), **직선+대각선이 한 타일 안에서 섞여 꺾이는 혼합 커브(신규)**
- **8방향 연결 지원**: 기존 상/하/좌/우(N/E/S/W) 직선 4방향에 더해, 대각선 4방향(NE/SE/SW/NW)으로도 선로가 연결될 수 있어 보드가 더 입체적이고 다양한 루트를 만들 수 있음 (회전/BFS/렌더링 로직 모두 8방향 일반화됨)
- **45도 단위 회전 (신규)**: 타일 회전이 기존 90도(4단계)에서 45도(8단계)로 세분화되어, 직선과 대각선이 한 타일에서 섞인 "혼합 꺾임" 타일도 정확히 맞춰 돌릴 수 있음
- **BFS 기반 통전 탐색**: 전원역에서 연결된 선로(직선+대각선 모두)를 따라가며 통전 상태를 실시간 계산
- **두껍고 둥근 파이프 모양 선로 (신규)**: 얇은 막대가 아니라 Loop Energy류 게임처럼 두껍고 끝이 둥근 튜브 모양으로, 여러 방향이 중심 허브에서 하나로 이어진 것처럼 보임
- 연결 안 된 선로는 어두운 슬레이트 네이비, 통전된 선로는 또렷한 전기 시안으로 확 밝아짐 (암흑 배경과의 대비로 타격감을 강조)
- 일반역에 불이 켜질 때 반짝이는 팝 애니메이션 효과
- 상태 메시지 실시간 갱신 ("노선을 복구하세요" → "N개 역 복구됨" → "OO선 복구 완료!")
- **수작업 노선 7개 + 그 이후 무한 생성 노선**, 뒤로 갈수록 타일 수 / 분기 수 증가
  1. 서율 순환선 (4×4, 역 1개 — 매우 쉬움)
  2. 도원 중앙선 (4×4, 역 2개)
  3. 강림 남부선 (5×5, 역 3개, T자 분기 등장)
  4. 여울 수변선 (5×5, 역 4개)
  5. 성류 공업선 (5×5, 역 5개, 가장 복잡)
  6. 빛가람 대각선 (5×5, 역 4개) — 전원역을 중심으로 네 모서리 역까지 오직 대각선(NE/SE/SW/NW)만으로 연결되는 X자 모양의 노선 — 8방향 연결을 처음 경험하기 좋은 스테이지
  7. 노을 갈림선 (5×5, 역 4개) — 전원역에서 네 방향으로 뻗어나가다가 각 가지 중간에 직선과 대각선이 한 타일 안에서 섞여 꺾이는 "혼합 커브"가 등장하는 가장 난이도 높은 스테이지 — 90도(4단계) 회전만으로는 맞출 수 없고 반드시 45도(8단계) 회전이 필요함
- **무한 모드 (신규)**: 7번 노선을 다 깨면 "모든 노선 복구 완료!" 배너가 한 번 뜨고, 그 뒤로는 "다음 노선"을 누를 때마다 노선이 즉석에서 새로 생성되어 끝없이 이어짐
  - 4가지 생성 패턴(방사형 꽃 / 프랙탈 분기 / 나선형 / 지그재그 격자)을 "가방 뽑기" 방식으로 섞어서, 연속 4판 안에 4가지가 반드시 한 번씩 다 나오게 함
  - 4방향 모드에서는 대각선이 전혀 안 나오게 생성 단계에서부터 방향을 제한 (생성 후 필터링이 아니라 애초에 대각선을 후보에서 제외)
  - 그리드는 처음 6판까지는 5×5, 그 이후부터는 6×6으로 커짐
  - 노선 이름도 수작업 노선과 같은 "지명+노선종류" 스타일로 무작위 조합(예: "한빛 회랑선")해서 어색하지 않게 이어짐
  - 생성된 노선이 사이클(가지끼리 겹침)이나 역 중복 없이 항상 풀 수 있는 모양인지 검증 후 통과한 것만 내보내고, 실패하면 재시도 후 방사형 꽃 패턴으로 대체
  - 생성 로직은 기존 `constructState`/`buildStageState`/`computeEnergized`/기차 애니메이션 로직을 전혀 건드리지 않고 그대로 재사용함 (`{name, rows, cols, power, stations, edges}` 형태만 맞춰서 만들어냄)
- 스테이지 데이터는 `STAGES` 배열로 완전히 분리되어 있어 새 노선을 쉽게 추가 가능
- 클리어 시 작은 기차 이모지(🚆)가 **실제로 복구된 노선 경로를 그대로 따라** 전원역부터 모든 분기까지 빠짐없이 이동하는 애니메이션 (Euler tour + Web Animations API로 구현)
- 클리어 후에는 타일 회전이 잠겨 더 이상 조작할 수 없음 (`cleared` 상태 관리)
- **연결되는 순간의 시각 이펙트**: 선로/역이 처음 통전되는 순간 타일 전체에 번쩍이는 스파크 플래시가 퍼지고, 역이 켜질 때는 중심에서 사방으로 터지는 링 + 스파크 파티클(7방향)이 추가로 재생됨 (어두운 배경과 대비돼 또렷한 타격감)
- **스테이지마다 다른 터널 색 배경 (신규)**: 노선 7개가 각각 전기 블루/바이올렛/틸/인디고/호박/마젠타/로즈 등 살짝 다른 "터널 색" 배경으로 순환되어, 배경이 하나로 단조롭지 않음 (선로·통전 색은 모든 테마에서 동일하게 유지해 가독성 유지)
- **사운드** (`assets/sfx`, `assets/music`의 실제 CC0 음원 파일 재생 — 출처/라이선스는 `assets/CREDITS.txt` 참고) — "신비한 터널을 질주하는 하이퍼 기차" 컨셉
  - 타일 회전 시: 짧고 깔끔한 클릭음 (`rotate.ogg`)
  - 선로 조각이 하나하나 연결될 때마다 가벼운 틱 사운드 (`track-connect.ogg`), **역에 실제로 전기가 들어오는 순간에는** 더 또렷한 확인음 (`station-connect.ogg`)이 따로 재생됨 — 회전 중에는 소리가 나지 않고, 회전 애니메이션이 끝난 타이밍에 맞춰 울림
  - 여러 선로/역이 한 번에 연결되면 순서대로 피치가 살짝 올라가며 재생
  - 스테이지 클리어 시: 승리 사운드(`clear.ogg`) 재생
  - **배경음악**: 질주감 있는 CC0 루프(`bgm.ogg`)를 그대로 반복 재생
  - 모든 음원은 `fetch` + `decodeAudioData`로 페이지 로드 시 미리 디코딩해두고, 재생은 Web Audio의 독립된 효과음/배경음악 버스를 통해 처리 (볼륨·음소거 로직은 기존과 동일)
  - 화면 우상단 스피커 아이콘을 누르면 **효과음 / 배경음악을 각각 독립적으로** 음소거하거나 슬라이더로 볼륨 조절 가능
- 마지막 스테이지까지 모두 클리어하면 "🎉 모든 노선 복구 완료! 🎉" 배너 표시
- "다음 노선" / "처음부터 다시" 버튼 제공
- 터치 디바이스를 고려해 타일/버튼 크기를 충분히 크게 설계

## 🔗 기능 진입점 (경로/파라미터)

- 단일 페이지: `index.html` (+ 상대경로 `assets/`의 사운드 파일) — 별도 라우팅, 파라미터, 서버 API 없음
- 모든 상태는 메모리(JS 변수) 내에서만 관리되며 새로고침 시 1스테이지부터 다시 시작

## 🚧 아직 구현되지 않은 기능

- 스테이지 진행 상황 저장(localStorage 등) — 새로고침하면 처음부터 다시 시작
- 사운드/음악 볼륨 설정 저장(localStorage) — 새로고침하면 기본값(효과음 70%, 배경음악 40%)으로 초기화
- 실제 광고 SDK 연동 (요청에 따라 placeholder만 존재)
- 타이머/점수/랭킹 시스템

## 💡 다음 개발 단계 제안

1. `localStorage`로 클리어한 최고 스테이지 및 사운드 볼륨 설정 저장 → 재방문 시 이어하기
2. 수작업 노선을 더 추가하고 싶다면 `STAGES` 배열에 `name / rows / cols / power / stations / edges`만 추가하면 됨 (혼합 꺾임 타일을 넣으려면 같은 타일에 직선 edge와 대각선 edge를 함께 연결하면 됨)
3. 무한 모드 생성 패턴을 더 추가하고 싶다면 `STAGE_FAMILIES` 배열에 같은 `(rows, cols, allowDiagonal) => {power, stations, edges}` 모양의 함수만 추가하면 "가방 뽑기"에 자동으로 합류함
4. 타이머/점수/랭킹 시스템 추가
5. (논의 중) 클리어할 때마다 큰 나무/정원 그림에 조각이 누적되는 메타 비주얼 — 퍼즐판과는 별도의 "진행 캔버스" 레이어로 설계 필요

## 🎨 비주얼 컨셉 — "신비한 터널을 질주하는 하이퍼 기차"

- 배경: 거의 암흑에 가까운 네이비 터널, 스테이지마다 살짝 다른 색조(바이올렛/틸/인디고/호박/마젠타/로즈 등)로 순환
- 타일: 카드 느낌을 걷어낸 미니멀한 칸 — 선로(파이프) 자체가 보이게 배경은 투명, 테두리는 얇은 헤어라인만
- 선로: 두껍고 끝이 둥근 파이프, 여러 방향이 중심 허브 아래에서 하나로 이어진 것처럼 보임
- 미연결 선로: 어두운 슬레이트 네이비 / 통전된 선로: 또렷한 전기 시안으로 확 밝아짐 (암흑 대비로 타격감 강조)
- 전원역: 번개 아이콘 (⚡, 펄스 애니메이션)
- 일반역: 작은 원형 역 아이콘, 복구 시 발광 + 팝 효과
- 클리어: 작은 기차(🚆)가 보드 위를 지나가는 애니메이션

## 🗂 데이터 모델

별도 데이터베이스나 Table API 없이, 모든 퍼즐 데이터는 `index.html` 내부의
JS 배열(`STAGES`)로 관리됩니다. 각 스테이지는 다음 구조를 가집니다:

```js
{
  name: '스테이지 이름',
  rows: 4, cols: 4,          // 격자 크기
  power: [r, c],              // 전원역 좌표
  stations: [[r, c], ...],    // 일반역 좌표 목록
  edges: [[r1,c1,r2,c2], ...] // 정답 상태에서 연결되는 인접 타일 쌍 (직선 4방향 + 대각선 4방향 모두 가능)
}
```

실행 시 `edges` 정보를 바탕으로 각 타일의 연결 방향 비트마스크(N/NE/E/SE/S/SW/W/NW 중 해당되는 비트)를 계산하고,
클리어되지 않은 상태가 되도록 무작위 회전(0~7, 45도 단위)을 부여해 퍼즐을 생성합니다. `edges`의 두 좌표 차이(dr, dc)가 직선 방향(상/하/좌/우)이든 대각선 방향(±1, ±1)이든 자동으로 인식되며, 같은 타일에 직선 edge와 대각선 edge가 동시에 걸리면 자동으로 "혼합 꺾임" 타일이 만들어집니다.

타일을 클릭하면 45도씩(8단계) 시계방향으로 회전합니다. 8방향 비트마스크를 1칸씩 순환시키는 `rotateMask45CW` 함수가 회전/판정 로직의 핵심이며, 기존에는 이 함수를 2칸씩(90도) 적용했지만 지금은 1칸씩(45도) 적용해 모든 대각선 방향을 거쳐가며 맞출 수 있습니다.

## 🌐 배포

**로컬 테스트 시 주의**: 사운드가 실제 음원 파일(`assets/...`)을 `fetch`로 불러오기 때문에,
`index.html`을 더블클릭해서 `file://`로 그냥 열면 브라우저 보안 정책상 사운드 파일 로딩이
막힐 수 있습니다. 로컬에서 확인할 때는 프로젝트 폴더에서 간단한 로컬 서버를 띄우고
(`python3 -m http.server`) `http://localhost:8000`으로 접속해 주세요.

실제 서비스로 배포할 때는 `index.html`과 `assets/` 폴더를 **함께** 같은 상대 경로 구조로
올려야 사운드가 정상 재생됩니다. **Publish 탭**에서 1클릭 배포를 진행하면 Publish 탭이
배포 과정을 자동으로 처리하고 라이브 사이트 URL을 제공합니다. (일반 HTTP(S) 서버로 배포되므로
이 문제는 생기지 않습니다 — `file://` 더블클릭 미리보기에서만 해당하는 제약입니다.)
