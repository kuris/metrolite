# ⚡ 서율 메트로 라이트 (Seoyul Metro Light)

정전된 가상 도시 **"서율"**의 지하철 노선을 복구하는 전기 연결 퍼즐 게임입니다.
타일을 터치해 45도씩(8방향) 회전시켜 전원역에서 모든 일반역까지 전기가 흐르게 만들면 클리어됩니다.

네온 보라/남색 톤의 밤 분위기와 민트빛 전력 이펙트로, 1판당 10~30초 정도 가볍게 즐길 수 있는
"잠깐 하는 지하철 전기 복구 퍼즐"을 목표로 제작했습니다.

---

## ✅ 현재 완성된 기능

- **단일 HTML 파일**로 동작 (`index.html` 하나로 완결, 외부 라이브러리 없음)
- 모바일 세로 화면 기준 UI이며, PC에서도 **중앙 정렬된 모바일 폰 프레임** 형태로 표시
- 4×4 / 5×5 격자 퍼즐판, 타일 터치 시 **45도씩(8단계) 회전** — 8방향 원형을 전부 활용해 한 번 클릭할 때마다 45도씩 돌아가며, 8번 누르면 원래 모양으로 돌아옴
- 타일 종류 구현: 직선, ㄱ자 커브, T자 분기, 십자 교차, 전원역(⚡), 일반역(●), **직선+대각선이 한 타일 안에서 섞여 꺾이는 혼합 커브(신규)**
- **8방향 연결 지원**: 기존 상/하/좌/우(N/E/S/W) 직선 4방향에 더해, 대각선 4방향(NE/SE/SW/NW)으로도 선로가 연결될 수 있어 보드가 더 입체적이고 다양한 루트를 만들 수 있음 (회전/BFS/렌더링 로직 모두 8방향 일반화됨)
- **45도 단위 회전 (신규)**: 타일 회전이 기존 90도(4단계)에서 45도(8단계)로 세분화되어, 직선과 대각선이 한 타일에서 섞인 "혼합 꺾임" 타일도 정확히 맞춰 돌릴 수 있음
- **BFS 기반 통전 탐색**: 전원역에서 연결된 선로(직선+대각선 모두)를 따라가며 통전 상태를 실시간 계산
- 연결 안 된 선로는 어두운 보라색, 통전된 선로는 민트/하늘색 네온으로 발광
- 일반역에 불이 켜질 때 반짝이는 팝 애니메이션 효과
- 상태 메시지 실시간 갱신 ("노선을 복구하세요" → "N개 역 복구됨" → "OO선 복구 완료!")
- **최소 5개 이상 스테이지** 구현(현재 총 7개), 뒤로 갈수록 타일 수 / 분기 수 증가
  1. 서율 순환선 (4×4, 역 1개 — 매우 쉬움)
  2. 도원 중앙선 (4×4, 역 2개)
  3. 강림 남부선 (5×5, 역 3개, T자 분기 등장)
  4. 여울 수변선 (5×5, 역 4개)
  5. 성류 공업선 (5×5, 역 5개, 가장 복잡)
  6. 빛가람 대각선 (5×5, 역 4개) — 전원역을 중심으로 네 모서리 역까지 오직 대각선(NE/SE/SW/NW)만으로 연결되는 X자 모양의 노선 — 8방향 연결을 처음 경험하기 좋은 스테이지
  7. **노을 갈림선 (신규)** (5×5, 역 4개) — 전원역에서 네 방향으로 뻗어나가다가 각 가지 중간에 직선과 대각선이 한 타일 안에서 섞여 꺾이는 "혼합 커브"가 등장하는 가장 난이도 높은 스테이지 — 90도(4단계) 회전만으로는 맞출 수 없고 반드시 45도(8단계) 회전이 필요함
- 스테이지 데이터는 `STAGES` 배열로 완전히 분리되어 있어 새 노선을 쉽게 추가 가능
- 클리어 시 작은 기차 이모지(🚆)가 **실제로 복구된 노선 경로를 그대로 따라** 전원역부터 모든 분기까지 빠짐없이 이동하는 애니메이션 (Euler tour + Web Animations API로 구현)
- 클리어 후에는 타일 회전이 잠겨 더 이상 조작할 수 없음 (`cleared` 상태 관리)
- **연결되는 순간의 시각 이펙트**: 선로/역이 처음 통전되는 순간 타일 전체에 번쩍이는 스파크 플래시가 퍼지고, 역이 켜질 때는 중심에서 사방으로 터지는 링 + 스파크 파티클(6방향)이 추가로 재생됨
- **사운드** (외부 음원 파일 없이 Web Audio API로 모든 소리를 직접 합성)
  - 타일 회전 시: 짧은 "틱" 클릭음
  - **선로가 실제로 맞물려 전기가 들어오는 순간에만**(회전 애니메이션이 끝난 타이밍에 맞춰) 또렷한 "팅~" 벨 사운드가 울림 — 회전 중에는 소리가 나지 않음
  - 여러 역이 한 번에 연결되면 화음처럼 순서대로 "팅팅팅" 재생
  - 스테이지 클리어 시: 5음으로 빠르게 치고 올라가는 팡파레 + 한 옥타브 위 스퀘어 반짝임을 겹쳐 더 화려하고 통통 튀는 "클리어!" 느낌
  - **배경음악**: Am→F→C→G 코드 진행 위에서 몰아치는 **신나는 신스-팝 루프** (오실레이터로 직접 생성, 외부 음원 없음)
    - 빠른 템포(스텝당 190ms)로 8스텝씩 오르내리는 아르페지오, 스퀘어+디튠 쏘투스를 겹친 두꺼운 리드 톤
    - 매 스텝 울리는 킥 + 다운비트마다 강조되는 사이드체인 덕킹(베이스가 순간 눌렸다가 되돌아오는 EDM식 펌핑감)
    - 다운비트가 아닌 스텝에는 화이트노이즈 기반 하이햇을 끼워 넣어 리듬을 촘촘하게 채움
  - 화면 우상단 스피커 아이콘을 누르면 **효과음 / 배경음악을 각각 독립적으로** 음소거하거나 슬라이더로 볼륨 조절 가능
- 마지막 스테이지까지 모두 클리어하면 "🎉 모든 노선 복구 완료! 🎉" 배너 표시
- "다음 노선" / "처음부터 다시" 버튼 제공
- 게임 하단에 실제 광고 코드 없는 **광고 영역 placeholder** 배치, 버튼과의 사이에 오클릭 방지용 여백 확보
- 터치 디바이스를 고려해 타일/버튼 크기를 충분히 크게 설계

## 🔗 기능 진입점 (경로/파라미터)

- 단일 페이지: `index.html` — 별도 라우팅, 파라미터, 서버 API 없음
- 모든 상태는 메모리(JS 변수) 내에서만 관리되며 새로고침 시 1스테이지부터 다시 시작

## 🚧 아직 구현되지 않은 기능

- 스테이지 진행 상황 저장(localStorage 등) — 새로고침하면 처음부터 다시 시작
- 사운드/음악 볼륨 설정 저장(localStorage) — 새로고침하면 기본값(효과음 70%, 배경음악 40%)으로 초기화
- 실제 광고 SDK 연동 (요청에 따라 placeholder만 존재)
- 타이머/점수/랭킹 시스템

## 💡 다음 개발 단계 제안

1. `localStorage`로 클리어한 최고 스테이지 및 사운드 볼륨 설정 저장 → 재방문 시 이어하기
2. 스테이지를 더 추가하고 싶다면 `STAGES` 배열에 `name / rows / cols / power / stations / edges`만 추가하면 됨 (혼합 꺾임 타일을 넣으려면 같은 타일에 직선 edge와 대각선 edge를 함께 연결하면 됨)
3. 광고 placeholder 영역에 실제 광고 네트워크 스크립트 연동 (정책상 승인된 코드만)
4. 타이머/점수/랭킹 시스템 추가

## 🎨 비주얼 컨셉

- 배경: 어두운 네온 그라데이션 (딥 네이비 → 퍼플)
- 타일: 둥근 사각형 카드, 미니멀 스타일
- 미연결 선로: 어두운 보라색 / 통전된 선로: 민트·하늘색 네온 발광
- 전원역: 번개 아이콘 (⚡, 펄스 애니메이션)
- 일반역: 작은 원형 역 아이콘, 복구 시 발광 + 팝 효과
- 클리어: 작은 기차(🚆)가 보드 위를 지나가는 애니메이션

## 🗂 데이터 모델

별도 데이터베이스나 Table API 없이, 모든 퍼즐 데이터는 `index.html` 내부의
JS 배열(`STAGES`)로 관리됩니다. 각 스테이지는 다음 구조를 가집니다:

```js
{
  name: '스테이지 이름',
  rows: 4, cols: 4,          // 격자 크기
  power: [r, c],              // 전원역 좌표
  stations: [[r, c], ...],    // 일반역 좌표 목록
  edges: [[r1,c1,r2,c2], ...] // 정답 상태에서 연결되는 인접 타일 쌍 (직선 4방향 + 대각선 4방향 모두 가능)
}
```

실행 시 `edges` 정보를 바탕으로 각 타일의 연결 방향 비트마스크(N/NE/E/SE/S/SW/W/NW 중 해당되는 비트)를 계산하고,
클리어되지 않은 상태가 되도록 무작위 회전(0~7, 45도 단위)을 부여해 퍼즐을 생성합니다. `edges`의 두 좌표 차이(dr, dc)가 직선 방향(상/하/좌/우)이든 대각선 방향(±1, ±1)이든 자동으로 인식되며, 같은 타일에 직선 edge와 대각선 edge가 동시에 걸리면 자동으로 "혼합 꺾임" 타일이 만들어집니다.

타일을 클릭하면 45도씩(8단계) 시계방향으로 회전합니다. 8방향 비트마스크를 1칸씩 순환시키는 `rotateMask45CW` 함수가 회전/판정 로직의 핵심이며, 기존에는 이 함수를 2칸씩(90도) 적용했지만 지금은 1칸씩(45도) 적용해 모든 대각선 방향을 거쳐가며 맞출 수 있습니다.
